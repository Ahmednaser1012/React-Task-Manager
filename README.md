Task Manager Dashboard

مشروع لإدارة المهام معمول بـ React و Tailwind CSS. الفكرة إني كنت محتاج أتعلم React أكتر وأعمل حاجة عملية أستخدمها لإدارة المهام اليومية.

نزل الـ dependencies:

npm install
