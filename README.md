React Task Manager Dashboard

تطبيق ويب لإدارة المهام مبني باستخدام React و Tailwind CSS. الهدف منه هو توفير واجهة سهلة وبسيطة تساعد على متابعة المهام اليومية، مع إمكانية الإضافة، التعديل، الحذف، والتصنيف.

خطوات تشغيل المشروع
المتطلبات

Node.js  

npm 

التثبيت والتشغيل

استنساخ المشروع:

git clone [رابط المشروع]
cd react-task-manager


تثبيت :

npm install


تشغيل المشروع :

npm run dev

npm run build


 
 ليه اخترت React؟

عندي خبرة سابقة مع React وأقدر أشتغل بيه بسرعة.

النظام بتاع المكونات (Components) بيسهل إعادة الاستخدام.

Virtual DOM بيخلي التحديثات أسرع.

مع مكتبات زي Redux Toolkit الموضوع بيكون منظم في إدارة الحالة.

كمان استخدمت Vite لأنه أسرع في التطوير من Create React App.
